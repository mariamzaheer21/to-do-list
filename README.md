# To-do-list
A simple to do list where you can add new tasks and delete the tasks. here HTML CSS and JavaSript is used!
JS is used to add the functionality of deleting and adding tasks. The To-Do App alerts a prompt to enter the text in the placeholder, if the user just clicks the "Add Button".
